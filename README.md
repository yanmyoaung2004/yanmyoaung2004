## Selected Projects

### K.I.N.E.T.I.C. — Multi-Agent AI Framework

A multi-agent system built with raw Python, HTTPX, and the OpenAI SDK, without relying on agent orchestration frameworks such as LangChain or CrewAI.

- Dispatcher-registry architecture for coordinating specialized agents.
- 6 agents and 80+ tools across 7 categories, with access-control mechanisms.
- Five-provider model failover, with persistent memory backed by SQLite and NumPy.
- Telegram, FastAPI, and CLI interfaces.
- Automated test suite with 89 tests, plus Ruff and mypy checks.

### InnoIgniterAI — AI-Powered Cybersecurity Platform

An agent-based cybersecurity platform combining threat intelligence, detection, and guided remediation.

- Specialized agents for planning, knowledge retrieval, and threat detection.
- Integrations with MITRE ATT&CK, VirusTotal, and Wazuh.
- Agent-to-agent communication and Model Context Protocol (MCP) integration.
- Security findings, monitoring, alerts, and automated remediation workflows.
- English and Myanmar language support, including text and voice interactions.

**Recognition:** APICTA 2025 Myanmar National Representative; APTYPS 2025 Top 10 Finalist and People's Choice Award recipient in the Cybersecurity & Privacy Chatbot Development Competition.

### Trace — Endpoint Security & Monitoring

A Go-based security monitoring project focused on endpoint detection and response.

- Security event collection and analysis.
- Detection rules implemented through a restricted YARA-compatible matcher in pure Go.
- Investigation into event ingestion, persistent storage, query performance, and crash recovery.
- Engineering work on bounded queues, storage overflow, and graceful degradation.

### Neon Aqua Oasis — VR Digital Twin

A virtual reality prototype exploring how digital twins can support human-centered community infrastructure planning before construction.

- Optimized 3D assets and a VR pipeline targeting standalone Meta Quest hardware.
- Explored infrastructure review through immersive virtual walkthroughs.
- Research presented in the context of community planning and stakeholder feedback.

**Research:** Submitted an ACAPHEI 2026 paper titled *From Virtual Walkthrough to Digital Twin: A Human-Centered Approach for Community Infrastructure Planning.*

More projects and implementation details are available on my [portfolio](https://yan-myo-aung.vercel.app) and [GitHub](https://github.com/yanmyoaung2004/).

## Current Research

### Reliability-Aware Multimodal Physiological AI

My final-year research investigates how ECG, PPG, and inertial measurement data can be used for physiological and activity-state recognition while estimating prediction reliability.

The focus is on handling noisy, missing, and contradictory sensor inputs rather than assuming every prediction is equally trustworthy.

Key interests include multimodal learning, sensor fusion, uncertainty and reliability estimation, and robust model evaluation.
